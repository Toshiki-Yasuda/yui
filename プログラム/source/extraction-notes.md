# 原稿抽出・固定記録

## 原本と保持方針

- 原本：`プログラム/午後コン　配布プログラムv2.pdf`（Canva作成、A4横・2ページ）。実ファイル名は `program.json` の `source_pdf` を参照。
- 原本SHA256：`7542cc3bd64d65e6df63f377aabfca9c832503e649e1c3374ccbd3203f742fca`
- 確認方法：Popplerの `pdftotext -raw` と `-layout`、原PDF両ページを1800pxで描画した画像を併用。曲順・本文・クレジット・段落の位置を照合した。
- 本文は省略・要約・校正を行わず固定。PDF紙面幅による折り返しだけを結合し、表示上の段落開始は `paragraphs` に分けた。
- 作曲者、作品の由来、奏法、出演者経歴、個人的な思い出に関する事実確認は実施していない。固定は原本との一致を指し、内容の事実確認済みを意味しない。

## 抽出上の注意と記録した修復

1. 元PDFのオブジェクト順と紙面の読む順序は異なる。raw抽出では第1部3曲目と4曲目の間に表紙情報が入り、第2ページ先頭にはプロフィールが入る。これらを本文に混ぜず、曲番号と紙面位置で切り分けた。
2. 表紙の `(Yui)` はraw抽出の第1ページ末尾に離れて出現する。紙面とlayout抽出を確認し、`event.title` に `午後のコンサート 〜 結 (Yui) 〜` として収録した。改行と文字サイズによる見た目の分離はデータ上の文字欠落にしない。
3. 装飾見出し `Profile` はraw抽出で重複し、文字間に分割も生じる。これはプロフィール本文ではなく見出し装飾のため、`artists` には収録していない。横罫線と名前の前の音符も装飾として収録していない。
4. プロフィール見出しの `土⽥祐⽣` は、`⽥`（U+2F65）を `田`（U+7530）、`⽣`（U+2F63）を `生`（U+751F）へ局所修復した。元PDFの表示と同じ名前 `土田 祐生` を格納。氏名中のスペースはlayout抽出と表示に合わせ、`安田 愛`、`田中 K助`、`土田 祐生` としている。曲本文にはこの修復を適用していない。
5. 本文中の英数字、括弧、引用符、大文字・小文字は保持。`Letters 6` と `letter` は別の曲名として原表記を維持した。第1部の休憩案内も全角数字を含む `※第１部終了後、１５分間の休憩を予定しております。` のまま保持。

## タイトル・クレジットの組版規則

- `title` は曲名のみ、`number` は曲番号。原本の `1.` などはレンダラーで組み立てる。
- `credits` は括弧等を含む**表示用の原表記**。例：`（J.S.バッハ）`、`（久石譲／安田愛編）`。レンダラー側でさらに括弧を加えない。
- ディズニーメドレーだけは原本の2つの曲目・作曲者行を各配列要素に分離した：`〜どこまでも（リン＝マニュエル・ミランダ）`、`〜アンダー・ザ・シー（アラン・メンケン／安田愛編）`。この「〜」は原表記として保持している。
- バッハのクレジットは原本では曲名の次行に右寄せされるが、文言は同じ `credits` に格納。クレジットの改行・位置・文字サイズは組版で扱う。
- イベントの開場・開演は時刻を `open` と `start` に分離。原本の表示は `開場 13:00 ／ 開演 13:30`。主催・後援のラベルも元の区分を保ち、団体名だけを各フィールドへ格納。
- 各プロフィールの最初の出身地・生年行と、続く経歴文は別段落として `bio` に保持。本文字数は順に148・131・115字。

## 未確認事項

- 原本本文の事実関係は未校閲。たとえば「赤とんぼ」の `幼くして母を失った` という表現は原本のまま保持しており、デザイン制作に伴って推測修正しない。
- 人名・作品の説明・引用風の記述・出演者の個人的な経験は、依頼者が内容修正を指示するまで原文を維持する。
- 紙面上の折り返しは新レイアウトで変わるため、最終PDFでは文字列照合に加えて、段落順・曲順・クレジット・文字欠けを目視確認する。
