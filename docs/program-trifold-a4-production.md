# A4配布用・三つ折りプログラム

2026年9月16日。A4用紙1枚を三つ折りにして配布する指定に合わせ、A3版を単純縮小せず実寸で再配置した。

## 仕様

- A4横297×210mm・両面。外三つ折り（Z折り）。仕上がり99×210mm。
- 曲目紹介は全曲10pt・行送り12pt。第2部は曲ごとに1段落とし、途中の段落改行を減らした。曲名10.5pt、作編曲者8pt。
- プロフィールは10.5pt／行送り14.5pt。出演者面の人物画を外し、名前・楽器名・紹介文を紙幅いっぱいに配置。
- 表紙は99:210の縦横比で新規構成した専用水彩画。3人を縦に配置し、上に公演名、下に日時・会場を組版。画像は`images/program-trifold/cover-narrow-v2.png`。
- 曲目紹介11曲は全文保持。プロフィールは直前の承認原稿を保持（安田愛は元PDFの短い略歴）。今回のA4化に伴う要約・削除はない。
- 文字を小さくすることは、2026年9月16日のユーザー回答「文章量は変えない」「文字はある程度小さいことを想定済み」に基づく。
- 二つ折り版・A3三つ折り版は別ファイルで保全。

## 出力と印刷

- `output/pdf/yui-program-trifold-a4.pdf`：実際に印刷するA4横2ページ。
- `output/pdf/yui-program-trifold-a4-reading.pdf`：読む順の99×210mm・6ページ。
- `output/pdf/yui-program-trifold-a4-10pt.pdf`／`yui-program-trifold-a4-10pt-reading.pdf`：従来の10pt比較版ファイル名でも同じ最新原稿を出力。

ラクスルの**外三つ折り・A4 1/3仕上がり**に合わせた配置。表面を正立で見て左端から99mmが山折り、198mmが谷折り。裏面を正立で見た場合も左が山折り、右が谷折りとなる。表面の左端が表紙、裏面の左端が裏表紙の出演者紹介となる。折り線の案内はPDFに印刷せず、入稿画面のガイドで確認する。

手元で試し刷りする場合は **A4・100％・両面短辺綴じ**。試し刷りで天地と折り向きを確認する。
