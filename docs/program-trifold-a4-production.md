# A4配布用・三つ折りプログラム

2026年9月16日。A4用紙1枚を三つ折りにして配布する指定に合わせ、A3版を単純縮小せず実寸で再配置した。

## 仕様

- A4横297×210mm・両面。外三つ折り（Z折り）。仕上がり99×210mm。
- 曲目紹介は9pt／行送り12pt。曲名10.5pt、作編曲者8pt。
- プロフィールは10.5pt／行送り14.5pt。出演者面の人物画を外し、名前・楽器名・紹介文を紙幅いっぱいに配置。
- 表紙は99:210の縦横比で新規構成した専用水彩画。3人を縦に配置し、上に公演名、下に日時・会場を組版。画像は`images/program-trifold/cover-narrow-v2.png`。
- 曲目紹介11曲は全文保持。プロフィールは直前の承認原稿を保持（安田愛は元PDFの短い略歴）。今回のA4化に伴う要約・削除はない。
- 文字を小さくすることは、2026年9月16日のユーザー回答「文章量は変えない」「文字はある程度小さいことを想定済み」に基づく。
- 二つ折り版・A3三つ折り版は別ファイルで保全。

## 出力と印刷

- `output/pdf/yui-program-trifold-a4.pdf`：実際に印刷するA4横2ページ。
- `output/pdf/yui-program-trifold-a4-reading.pdf`：読む順の99×210mm・6ページ。

印刷は **A4・100％・両面短辺綴じ**。左端から99mmと198mmで交互に折る。巻き三つ折りではなくZ折り。表面の左端が表紙、裏面の右端が出演者となり、この2面が折り上がりの外側に出る向きで折る。試し刷りで天地と文字サイズを確認する。

| 面 | 左 | 中央 | 右 |
|---|---|---|---|
| 表面 | 表紙 | 第1部1〜3曲 | 第1部4〜5曲・休憩 |
| 裏面 | 第2部1〜3曲 | 第2部4〜6曲 | 出演者紹介 |

## 再生成・検証

```bash
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib .venv-print/bin/python scripts/build-program-trifold.py --paper a4
```

専用HTMLは`program-trifold-a4.html`、追加スタイルは`css/program-trifold-a4.css`。原稿・フォント・水彩画は既存資産を参照。

6面のページ数、全文・公演情報一致、文字の端から5mm以上の余白、本文とフッターの間隔、面付け各領域の文字一致を検査。両面PDFと出演者面の画像を目視確認。フォントは埋め込み済み。実物の試し刷りは未実施。
