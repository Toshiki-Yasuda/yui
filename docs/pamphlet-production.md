# 三つ折りパンフレット 制作・印刷メモ

2026年9月13日。ユーザーから「現在のサイトのクオリティーに引き上げて」と依頼を受け、旧冊子を全面改訂。Web本体と `flyer.html` は今回変更していません。

## 成果物と編集箇所

- `pamphlet.html`：6面の内容と画面プレビュー。PDFの原稿もこのHTML
- `css/pamphlet.css`：冊子専用スタイル。Webと同じクリーム・ローズ・明朝体を使い、寸法は印刷用のmm/ptで独立管理
- `js/pamphlet-preview.js`：プレビューを画面幅に合わせる処理。印刷・PDFのレイアウトには使わない
- `output/pdf/yui-pamphlet-a4.pdf`：297 × 210mm、2ページ、A4原寸確認・両面印刷用
- `output/pdf/yui-pamphlet-bleed.pdf`：303 × 216mm、2ページ、四辺3mmの塗り足し付き。TrimBoxとBleedBoxを設定
- `fonts/print/`：Noto Sans JP 400/500、Noto Serif JP 400の使用文字サブセットとOFLライセンス。PDFにもフォントを埋め込む
- `images/print/`：チケット・公式サイト・OFUSEのベクターQR。4モジュールの余白を持つ

冊子のHTML/CSSを変えたら必ずPDFを再生成すること。PDFには原稿ハッシュを保存し、検証スクリプトで古い出力を検出する。

## 面付けと折り

A4横の巻き三つ折りを想定。外面の左側を内側へ折り込み、右側の表紙を閉じる。仕上がりは100 × 210mm。

| PDF | 左 | 中央 | 右 |
|---|---|---|---|
| 1ページ目・外面 | 折込面／コンセプト 97mm | 裏表紙／チケット・アクセス 100mm | 表紙 100mm |
| 2ページ目・中面 | プログラム 100mm | 安田愛プロフィール 100mm | 共演者・Web・OFUSE 97mm |

外面は左から97mm・197mm、中面は左から100mm・200mmが折り位置。上記は仕上がり左端基準で、塗り足し付きPDFではそれぞれ3mmを加える。表裏の折り位置を同じ数値にしないこと。

旧版の「裏表紙｜表紙｜折込面」という並びと寸法を修正した。現在の画面上の点線は確認用で、印刷PDFには入らない。トンボは追加せず、PDFのページボックスで仕上がりを指定している。

家庭・オフィスでの確認はA4横、倍率100%、両面短辺綴じ。フチなし非対応機では背景の端に白が残る場合がある。最初に1枚で表裏・折り順を確認する。

印刷会社が決まったら、その商品のテンプレートと照合すること。巻き込む面を小さくする原則と見開きでの入稿は[ラクスルの折りパンフレット仕様](https://raksul.com/print/pamphlet/)・[入稿案内](https://raksul.com/guide/submit-data/preflight/folding-products/)を参考にした。紙厚や業者指定により面幅・塗り足し・トンボの要否が異なる場合がある。

## 情報と編集方針

- 元のコンセプト全文、主演の経歴、公演日時、料金、購入後の連絡依頼を保持
- 住所表記・確定した後援4団体・終演予定・全席自由・当日券・JRアクセスは現在の `index.html` と照合
- 田中K助、土田祐生の紹介を追加。ユーザーの「共演者のプロフィールに偏り」という指摘に対応し、サイトの経歴を71字／73字に要約。お二人とも出身・肩書き・主な活動を紹介し、同じ3行に揃えた。写真は同じ58 × 28mmの枠で全体を表示し、人物を切らない。詳しい経歴は公式サイトQRへ案内。新しい経歴は創作しない
- 主演の所属に、現在のサイトに記載された北海道打楽器協会を反映
- 曲数案内はユーザー確定文言の「当日のお楽しみも含め、全12曲程度をお届けする予定です。」
- 「結」の曲紹介は旧冊子にある説明を保持。曲順は当日の演奏順を確定するものではなく、掲載曲目の順序
- 応援の見出しはユーザー確定文言「応援・ご支援はこちらから」
- Webの大きなヒーローをそのまま縮めず、表紙の絵を58mm幅に配置して既存684px画像でも約300ppiを確保

## 再生成

Python 3.12で作成。WeasyPrintはPango等のネイティブライブラリが必要。今回のMacにはHomebrewのPangoが既にあり、下記のライブラリ検索パスで使用した。

```bash
python3 -m venv .venv-print
.venv-print/bin/python -m pip install -r scripts/print-requirements.txt

# 文章を変更して新しい文字を使った場合。初回のみGoogle Fonts公式から元書体を取得する
.venv-print/bin/python scripts/prepare-pamphlet-assets.py

# macOS / Apple Siliconでの生成（Linux等では環境に合わせてライブラリ検索パスを省略）
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib .venv-print/bin/python scripts/build-pamphlet.py
.venv-print/bin/python scripts/check-pamphlet.py

# Web本体・既存チラシに影響がないことも確認
python3 scripts/check-site.py --baseline cd9b215
node --check js/pamphlet-preview.js
git diff --check
```

`check-pamphlet.py` はPopplerの `pdftoppm` を使用する。検証用PNGやFontconfigキャッシュは `tmp/pdfs/` 以下で、公開・コミット対象外。

## 検証と限界

- 外面・中面のPDFをPNG化し、線画、余白、文字の重なり、人物の切り取りを修正して再確認
- ブラウザは1159px・847px・390px幅で実画面を確認。文書全体の横はみ出しなし。6面の文字領域が紙面に収まり、共演者2人の紹介欄の高さが一致することをDOM寸法でも照合
- PDFは2ページ、用紙寸法は上記と一致。本文は選択・検索可能で、日本語書体と英字書体を全て埋め込み
- テキストの折り目・断裁線からの距離を生成時に検査（最低5mm、計算許容0.1mm）。プログラム下端も8mm以上確保
- 縮小プレビューでは変形前の空白領域をスクロールさせない。画面用の縮小寸法は印刷時に解除し、303 × 216mmに戻す。本文を隠して紙面に収める実装にはしない
- 主演プロフィールは9pt。本文は用途に応じて8〜9.3pt、補足・QR説明のみ小さくして情報に優先度を付けた
- 写真は配置後300ppi以上。QRは最終A4 PDFの150dpi画像から3つとも読み取り、元のURLと一致することを検証
- 出力はRGB PDF。PDF/X・業者指定CMYKプロファイルへの変換はしていない。紙・印刷機による発色と実物の折りは試し刷りで確認する
- 印刷発注・入稿・Webへの公開はこの冊子改訂依頼では実行していない

「電子データを検証済み」と「印刷会社で校了・入稿済み」を混同しないこと。公開依頼があった場合は、HTML・CSS・JS・フォント・QR・2つのPDFを一緒に反映する。
