# マリンバ紹介ページ改訂（2026-09-18）

ユーザー承認の構成で marimba.html と css/marimba.css を改訂。

- 一般的な楽器の紹介 → 響きのしくみ → 公演約2か月前に譲り受けたご縁 → 特注の最高音を使う今回の演奏 → 会場への案内。
- イメージ用の既存水彩画を使用。実機写真、動画の埋め込み、3D表示は掲載しない。3Dのファイル自体は保存。
- 個体の仕様・入手経緯・最高音を使う演奏構成はユーザー提供情報。一般構造と奏法はヤマハ、標準モデル仕様はADAMS公式資料を参照し、ページ末尾に資料リンクを掲載。
- 正確な最低音・最高音、音板数、希少性の順位など未確認の数値・表現は追加していない。

## 検証

- python3 scripts/check-site.py：両ページのリンク・素材・見出し・画像寸法の確認に合格。
- node --check js/site.js、git diff --check：合格。
- Chromiumで390×844、768×1024、1440×1000、1920×1080の全体画像を確認。320×740も含め横はみ出しなし。
- スマートフォンのメニュー開閉・Escape、JavaScriptエラーなしを確認。
- 本文の全面改稿はユーザーの明示的な依頼。旧本文保存を前提とする --baseline 比較は今回の楽器紹介ページには適用していない。
- ローカルプレビューのみ。公開作業はしていない。

## 仕上げの確認

- 水彩画の外周を背景へなじませ、音板・共鳴管の注記を説明番号と対応させた。
- 最高音の下線をなくし、意味を持つstrong要素で強調。今回の演奏構成についての説明を明確化。
- スマートフォンの章間と「結」の余白を整理。390px幅の全体高は約5596pxから5177pxへ短縮。
- 公演案内を淡い背景とワイン色の見出しに変更。
- 320/390/768/1440/1920pxで横はみ出し・JavaScriptエラーなし。スマートフォンとPCの画像を目視確認。
- モーション低減環境でページ内リンクの移動先が固定ナビの下に表示されること、参考資料をEnterキーで開けること、JavaScriptなし・320px幅でも本文が表示されることを確認。
