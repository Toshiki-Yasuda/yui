# 「結」当日プログラム・文字を大きくした三つ折り版

2026年9月16日制作。既存の二つ折り版と別ファイルで保管。

## 仕様と読みやすさ

- A3横420×297mm、両面。**外三つ折り（Z折り）**、各面140×297mm。
- 表紙1面、曲目紹介4面、出演者紹介1面。表紙と出演者紹介の面積を減らし、曲目紹介に紙面を配分した。
- 曲目紹介・プロフィールは**12.5pt／行送り18pt**。二つ折り版の10.5ptから文字の高さを約19％拡大。
- 曲名14pt、作編曲者10.5pt、主催後援10.5pt。曲番号15pt。
- 曲目紹介の左右余白は8mm。曲を面の途中で分割しない。
- 11曲の紹介文は全文掲載。出演者面を再構成し、**安田愛のプロフィールはユーザー指示により元PDFの148字の略歴へ復帰**。共演者の原稿は維持。
- 3人の人物画を23mmから36mmへ拡大し、名前・楽器名と組み合わせた見出しを統一。本文12.5ptを維持し、人物紹介の間隔を確保。
- 水彩、筆文字、生成り、ローズとゴールドのトーンを継承。既存の画像を再利用。
- 表紙画は幅140mmで全体を収めるため、実効約191ppi。新たな高解像度生成・単純拡大は行っていない。

## ファイル

- `output/pdf/yui-program-trifold-a3.pdf`：印刷用A3・2ページ。
- `output/pdf/yui-program-trifold-a3-reading.pdf`：読む順の140×297mm・6ページ。印刷用の面付けには使わない。
- `program-trifold.html`、`css/program-trifold.css`、`scripts/build-program-trifold.py`：三つ折り専用の生成ファイル。
- 本文は`プログラム/source/program.json`を参照し、三つ折り専用の`プログラム/source/program-trifold-overrides.json`で安田愛の略歴のみ上書き。二つ折り版の全文プロフィールは変更しない。
- 短い原稿へ戻した際に必要となる「傍」を含む本文フォントを`fonts/program-trifold/`へ独立保存。元のNoto Serif JPから400ウェイトで生成し、ライセンス同梱。既存の二つ折り用フォントは変更していない。

## 印刷と折り

印刷用PDFを**A3・原寸100％・両面・短辺綴じ**で印刷する。左端から140mm、280mmを交互の向きに折る。内側へ巻き込む巻き三つ折りではない。まず1枚で表裏の天地と折り順を確認する。

| 印刷面 | 左 | 中央 | 右 |
|---|---|---|---|
| 1 | 第2部4〜6曲目 | 出演者紹介 | 表紙 |
| 2 | 第1部1〜3曲目 | 第1部4〜5曲目・休憩 | 第2部1〜3曲目 |

読む順：表紙 → 第1部前半 → 第1部後半 → 第2部前半 → 第2部後半 → 出演者紹介。

折り線・トンボ・塗り足しは印刷用PDFに付けていない。フチなし非対応のプリンターでは紙の外周に白い余白が残るが、文字は端から5mm以上内側に収めている。

## 再生成と確認

```bash
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib .venv-print/bin/python scripts/build-program-trifold.py --paper a3
```

全6面・両面のPDF画像を目視確認。フォントは埋め込み済み。画面サイズ別の検証は対象外。実物の試し刷りは未実施。
