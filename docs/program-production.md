# 「結」当日配布プログラム 制作・印刷メモ

2026年9月15日制作、9月16日表紙改訂。A3横を二つ折りにしたA4縦・4ページ。曲目紹介の全文を主役に、既存サイトと三つ折り冊子の生成り・ローズ・明朝体・水彩を引き継いだ。

## ファイルの使い分け

| ファイル | 用途 |
|---|---|
| `output/pdf/yui-program-a3.pdf` | **実際に二つ折り印刷する原稿**。A3横420×297mm、2ページ |
| `output/pdf/yui-program-a4.pdf` | 読書順で見る原稿。A4縦210×297mm、4ページ |
| `output/pdf/yui-program-a3-bleed.pdf` | 外周3mm塗り足し付き。426×303mm、2ページ。印刷会社の指定と照合して使う |

| `プログラム/source/extraction-notes.md` | 原本との照合、抽出修復、承認された原稿更新 |

元PDF、指定の3人の水彩画、承認ラフは`プログラム/`以下に保全。ラフ画像内の仮文章は使用していない。既存のサイト・チラシ・三つ折り冊子の原稿とPDFは変更していない。

## 印刷する場合

1. `yui-program-a3.pdf`を開く。
2. 用紙を**A3、原寸100%、両面、短辺綴じ**に設定する。「用紙に合わせる」は切る。
3. まず1枚試し刷りし、表裏の天地を確認する。プリンターの反転設定で結果が異なる場合がある。
4. 中面を開くと左が第1部、右が第2部になるよう、中央で二つ折りにする。

| 面 | 左 | 右 |
|---|---|---|
| 外面 | 裏表紙・出演者紹介 | 表紙 |
| 中面 | 第1部・5曲 | 第2部・6曲 |

折り位置はA3原寸版の左端から210mm。塗り足し版では左端から213mm。印刷機に余白が必要な場合は紙の周囲に未印刷部分が残るため、全面の生成り色を再現するには印刷先の対応を確認する。

塗り足し版はMediaBox/BleedBox 426×303mm、TrimBox (3,3)〜(423,300)mm。中央の折り目に余計な塗り足し帯はない。トンボは付けていない。

## 画像・装飾

- 表紙は指定された3人の画像と承認ラフを参照し、imagegenで筆文字「結」、手書きの「Yui」、水彩、細線、金色の小さな点を一体化した新しい画へ再構成。元画像は保全。生成による描き直しを含み、画素単位で元絵と同一ではない。
- 上部の公演名・下部の日時会場は明朝体の文字データとして重ね、印刷時の鮮明さと正確さを保持。9月16日の追加調整で、日付を「2026年 10月25日（日）」へ変更。月日の数字30pt、年15.5pt、開場開演11.5pt、会場11pt／主会場名12.5ptとし、情報全体を4mm上げて下端の余白を確保。
- 画像内の「結」「Yui」は目視照合し、`images/program/cover-art-review.json`に対象画像のハッシュと検証文字を記録。画像変更時は再照合が必要。実用情報と全本文の文字一致検査は継続。
- 元の縁グラデーションがPDFで白い帯として見えたため、表紙・裏表紙の重ね処理を撤去。白い筋は意図した装飾ではない。
- 裏表紙の3人は、既存の人物画を参照してimagegenで個別の透過水彩へ整えた。元画像は保全し、`portrait-*-v2.png`として別保存。各1254×1254px。透明な不規則の輪郭をそのまま配置し、矩形の縁ぼかしは使用しない。生成による描き直しを含む。
- 裏表紙の下部に、本文と主催後援の間隔を確保してマリンバと4本のマレットの透過水彩を小さく配置。
- 中面の見出し・休憩案内の罫線をローズで統一。曲番号を傾きのない数字にそろえ、段間に0.25ptの淡い縦罫を追加。本文のサイズ・段幅・全文を保持。
- 表紙画像は1054×1492px、216×303mm配置で実効約124ppi。高解像度を指定した再生成でも返却寸法は同じだったため、300ppi相当とは扱わない。筆文字・水彩の原寸試し刷りを要する。日時・会場の文字データはこの解像度に制約されない。
- 裏表紙中央の二重波線は削除。左の「結・Yui」と右のマリンバ水彩の間を余白とし、装飾の重複を整理。

## 再生成

制作時は、以前のローカル制作環境に残っていた同じPython 3.12用の依存と元フォントを再利用した。新規環境では次の手順で必要な依存を導入する。

```bash
python3.12 -m venv .venv-print
.venv-print/bin/python -m pip install -r scripts/program-requirements.txt

# 本文に新しい文字を追加したとき。元フォントはキャッシュを再利用し、なければGoogle Fonts公式から取得する
.venv-print/bin/python scripts/prepare-program-assets.py

# macOS / Apple Silicon。Linux等では環境に応じてDYLD設定を省略する
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib .venv-print/bin/python scripts/build-program.py
.venv-print/bin/python scripts/check-program.py
```

制作環境のPython実体は`/Users/yasudaai/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`。WeasyPrint 70.0、pypdf 6.18.1、fonttools 4.65.0を使用。PangoとPoppler（pdftotext/pdffonts/pdftoppm）が必要。

1. `build-program.py`がJSONからHTMLを生成する。HTMLの本文を直接編集しても次回ビルドで上書きされる。
2. `program_pdf.py`が216×303mm・4ページの内部マスターを一度組版し、原寸・面付け・塗り足しの3版へ出力する。
3. 旧三つ折り用の`prepare-pamphlet-assets.py`は実行しない。プログラム専用フォントは`fonts/program/`へ保存する。
4. フォントのOFLライセンスを同梱。英数字装飾には制作環境のGeorgiaを使用し、PDFへ埋め込んでいる。別環境でGeorgiaがない場合は代替による外観差を確認する。
5. JSON、ビルドコード、CSS、使用画像、フォントのハッシュをPDFへ保存し、古い出力を検査で検出する。
6. Notoの全角チルダ（U+FF5E）と波ダッシュ（U+301C）は元フォントで同じ字形を共有する。専用フォントでは字形と寸法を保ったまま別のグリフIDへ分け、PDFからの文字抽出でもユーザー原稿の「～」を保持する。

- 3種のPDFの寸法とページボックス、外面4｜1／中面2｜3が一致。実際のPDF左右領域の文字も読書順PDFと照合。

- PDF全4ページと印刷用A3両面を画像化して確認。独立レビューの末尾行の指摘を微調整へ反映。
